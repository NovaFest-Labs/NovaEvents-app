# Security Policy

NovaEvents handles wallet connections and on-chain transaction signing, so we take security reports seriously.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report privately using GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/NovaFest-Labs/NovaEvents-app/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, including steps to reproduce, affected components, and potential impact.

## What to Expect

- We will acknowledge your report within a few business days.
- We will keep you updated as we investigate and work on a fix.
- Once a fix is released, we are happy to credit you if you wish.

## Scope

This policy covers the code in this repository (the NovaEvents frontend), including wallet connection and transaction signing flows.
